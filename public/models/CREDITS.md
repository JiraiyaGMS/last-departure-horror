# Model credits

Everything in this folder is **CC0** (public domain). No attribution is legally
required; it is given here because it is deserved.

- `cast.glb` — the Attendant, the fourteen passengers and the Bay 0 driver,
  generated with [MPFB](https://github.com/makehumancommunity/mpfb2) from
  MakeHuman's CC0 system assets. See `tools/cast/README.md`.
- `props.glb` — the station's clutter: bins, crates, barrels, suitcases,
  shelving, chairs, the CCTV cameras and the rest, photo-scanned models from
  [Poly Haven](https://polyhaven.com/models) (https://polyhaven.com/license).
  The full list of sources is in `tools/props/README.md`.
