# Texture credits

Every surface texture in this folder is a photo-scanned PBR material released
under **CC0** (public domain). No attribution is legally required; it is given
here because it is deserved.

Each material ships as three maps: `_diff` (colour, sRGB), `_nor` (OpenGL
normal map) and `_arm` (ambient occlusion / roughness / metalness packed into
R / G / B). `1k/` holds the 1024px versions of the large surfaces, `512/` the
512px versions of everything.
